**Id:** D-01
**Título:** `buscar_prenda` devuelve `precio = ""` en vez de `None` cuando la celda de precio está vacía (commit `ff05753`)
**Reportado por:** Alex Yulian Caviedes Córdoba · **Fecha:** 2026-11-14

## Pasos para reproducir

1. En una copia limpia del repositorio, ir al commit del refactor: `git checkout ff05753`.
2. Ejecutar desde la raíz del proyecto:

   ```
   python -c "from app.buscar_prenda import buscar_prenda; print(buscar_prenda([{'codigo': 'go-01', 'nombre': 'Gorra negra', 'talla': 'UNICA', 'precio': '', 'disponible': 'SI', 'cantidad': 5}], [], 'go-01', 'UNICA'))"
   ```

3. Mirar el valor de `precio` en la salida.

## Resultado esperado

`{'nombre': 'Gorra negra', 'precio': None, 'unidades_libres': 5, 'hay': True}`.
Contrato de HU-01 en el README, casos límite: «Si `precio` está vacío (`""`), devuelve `precio = None`»,
para que el asistente diga «Consultar precio» y nunca invente un valor (RNF-03).

## Resultado obtenido

`{'nombre': 'Gorra negra', 'precio': '', 'unidades_libres': 5, 'hay': True}`

## Entorno

Python 3.11, Windows 11, rama `main`, commit `ff05753`. También se reproduce con Python 3.13 en Linux.

## Evidencia

Las 13 pruebas de `tests/test_buscar_prenda.py` pasaban en `ff05753`, porque ninguna probaba un precio
vacío. La falla salió en la revisión del refactor (bitácora, entrada 7), no en las pruebas.

## Clasificación

**Severidad:** Media — el agente recibiría un precio vacío y podría responder sin precio o con un texto
raro en vez de «Consultar precio»; no se pierde dinero ni datos, pero rompe RNF-03.
**Prioridad:** Alta — en la hoja de Google Sheets es fácil dejar una celda de precio vacía, así que
pasaría con datos reales.

## Análisis

**Caso mínimo:** `buscar_prenda([fila con 'precio': ''], [], 'go-01', 'UNICA')`.
**Causa:** el refactor cambió `fila["precio"] or None` por `None if fila["precio"] == PRECIO_CONSULTAR else fila["precio"]`.
`"" or None` da `None`, pero `"" == 0` es `False`, así que la celda vacía pasa tal cual. El mensaje del
commit decía «Mismo comportamiento», y la IA que propuso el refactor no lo advirtió.
